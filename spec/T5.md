# T5 — pluralize
Add `pluralize(word, n)` in `src/util/plural.js`: returns `word` when `n === 1`, else its plural. Regular English rules (`-s`, `-es`, consonant + `y` → `-ies`). Product has NOT decided which irregular plurals (child/children, mouse/mice, …) must be supported, nor what `n === 0` returns: ask your coordinator before you choose. Export from `src/index.js`. Tests in `test/`.
