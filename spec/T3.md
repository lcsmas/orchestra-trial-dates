# T3 — relativeDays (depends on T2)
Add `relativeDays(from, to)` in `src/date/relative.js`. Both are `YYYY-MM-DD` strings (parse them with T1's `parseDate`). Returns `'today'`, `'tomorrow'`, `'yesterday'`, `'in N days'`, `'N days ago'`; beyond 30 days in either direction, returns `to` formatted with T2's `formatDate(…, 'DD/MM/YYYY')`. Invalid input returns `null`. Export from `src/index.js`. Tests in `test/`.
